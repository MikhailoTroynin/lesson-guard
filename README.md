# Lesson Guard

Android-додаток для батьків. Він стежить за завданнями дитини в **Google Класі** та оцінками в **«Єдиній школі»** і надсилає сповіщення, коли:

- 📘 вчитель додав **нове завдання** (наприклад, у понеділок);
- ⛔ за урок/завдання з’явилася **погана оцінка** (за замовчуванням нижче 7 за 12-бальною шкалою, поріг налаштовується). Оцінка автоматично прив’язується до завдання з цього предмета, тож видно, що «5 у середу» — це за «Задачі № 112–118» з понеділка;
- ⚠️ дитина **здала порожню роботу**: позначила «Здано», але нічого не прикріпила, або прикріплений Google-документ/презентація/таблиця порожні.

Перевірка запускається у фоні кілька разів на день, а також вручну (кнопка «Перевірити зараз» або потягнути екран вниз).

## Демо

**https://mikhailotroynin.github.io/lesson-guard/**

Веб-версія працює на вигаданих даних. Натискайте «Наступний день ▶», щоб пройти тиждень: нове завдання → порожня здача → оцінка 5. На вкладці «Сповіщення» з’являться відповідні алерти.

На комп’ютері демо показується в макеті смартфона (як у дизайні), на телефоні — на весь екран.

> Демо публікується в гілку `gh-pages`. Один раз налаштуйте Pages: **Settings → Pages → Build and deployment → Source: Deploy from a branch → Branch: `gh-pages` / `(root)`**. Після цього кожне оновлення `main` перезбирає сайт.

### Автоматичне злиття в `main`

Workflow **Auto-merge to main** (`.github/workflows/auto-merge.yml`) спрацьовує на push у будь-яку гілку, крім `main`: проганяє lint, typecheck, тести й веб-збірку, а потім вливає гілку в `main` (fast-forward або merge-коміт) і запускає деплой GitHub Pages та збірку APK. Якщо на `main` увімкнено захист гілки, дозвольте `github-actions[bot]` пушити в неї, інакше крок злиття впаде.

## Встановлення на Android

1. Відкрийте вкладку **Actions → Android APK**, виберіть останній успішний запуск і завантажте артефакт `lesson-guard-apk`. Для версій із тегом `v*` APK також прикріплюється до **Releases**.
2. Встановіть APK на телефон (дозвольте встановлення з невідомих джерел).
3. Дозвольте сповіщення.
4. Спершу додаток відкривається в демо-режимі. Щоб бачити реальні дані, підключіть акаунти (нижче) і вимкніть «Демо-режим» у налаштуваннях.

## Підключення Google Класу

Додаток читає дані через Google-акаунт **дитини** (лише читання). Батьківський доступ (guardian) через API не показує зданих робіт, тому потрібен саме акаунт дитини.

Одноразове налаштування в [Google Cloud Console](https://console.cloud.google.com/):

1. Створіть проєкт.
2. **APIs & Services → Library:** увімкніть **Google Classroom API** і **Google Drive API**.
3. **OAuth consent screen:** тип *External*, режим *Testing*. У **Test users** додайте email дитини. У режимі тестування верифікація від Google не потрібна.
4. **Credentials → Create credentials → OAuth client ID → Android:**
   - Package name: `com.mikhailotroynin.lessonguard`
   - SHA-1: `5E:8F:16:06:2E:A3:CD:2C:4A:0D:54:78:76:BA:A6:F3:8C:AB:F6:25` (стандартний debug-ключ, яким підписується APK з Actions). Якщо ви налаштували власний ключ (див. нижче), вкажіть його SHA-1.
5. *(Необов’язково)* Створіть також OAuth client ID типу **Web** і додайте його в репозиторій як змінну `GOOGLE_WEB_CLIENT_ID` (**Settings → Secrets and variables → Actions → Variables**).

Потім у додатку: **Налаштування → Google Клас → Увійти через Google**.

Скоупи, які запитує додаток:

| Скоуп | Навіщо |
|---|---|
| `classroom.courses.readonly` | список курсів дитини |
| `classroom.coursework.me.readonly` | завдання та здані роботи дитини |
| `drive.readonly` | перевірити, чи прикріплені документи не порожні |

Шкільні акаунти Google Workspace for Education можуть блокувати сторонні додатки на рівні адміністратора школи. У такому разі вхід поверне помилку доступу, і доведеться просити адміністратора дозволити додаток.

## Підключення «Єдиної школи»

Офіційного API в «Єдиної школи» немає. Додаток має входити з логіном і паролем батьків і читати щоденник так само, як це робить вебсайт. **Ця частина ще не реалізована.** Логін і пароль уже можна зберегти в налаштуваннях: вони лежать лише на телефоні, у зашифрованому сховищі Android. Оцінки поки що доступні тільки в демо-режимі.

Щоб реалізувати клієнт, потрібен запис мережевих запитів вебверсії:

1. Відкрийте «Єдину школу» в Chrome на комп’ютері, натисніть F12 і перейдіть на вкладку **Network**. Увімкніть **Preserve log**.
2. Увійдіть, відкрийте щоденник/оцінки дитини, перегорніть тиждень.
3. Клацніть правою кнопкою в списку запитів і виберіть **Save all as HAR**.
4. **Перш ніж комусь передавати файл, змініть пароль або видаліть його з HAR.** Файл містить пароль і cookie сесії.

За цим записом реалізується `src/providers/eschool/client.ts`.

## Власний ключ підпису (необов’язково)

Без налаштувань APK підписується стандартним debug-ключем. Щоб підписувати власним ключем, згенеруйте keystore і додайте секрети репозиторію:

```bash
keytool -genkeypair -v -keystore release.keystore -alias lessonguard -keyalg RSA -keysize 2048 -validity 10000
```

```bash
base64 -w0 release.keystore
```

Секрети: `ANDROID_KEYSTORE_BASE64` (вивід останньої команди), `ANDROID_KEYSTORE_PASSWORD`, `ANDROID_KEY_ALIAS`, `ANDROID_KEY_PASSWORD`. Не забудьте вказати SHA-1 нового ключа в Google Cloud (`keytool -list -v -keystore release.keystore`).

### Структура

```
src/app/            екрани (Expo Router): Огляд, Сповіщення, Налаштування
src/core/           правила без залежностей від платформи (покриті тестами)
  rules.ts          погана оцінка, порожня здача, нормалізація назв
  matcher.ts        прив’язка оцінки до завдання (предмет + дата)
  checker.ts        одна перевірка: дані + попередній стан → нові алерти
src/providers/      джерела даних: Google Клас, Єдина школа, демо-сценарій
src/services/       збирання даних і повна перевірка (для екрана й фону)
src/platform/       сховище, секрети, сповіщення, фонова задача, вхід Google
```

Стек: Expo SDK 58 (React Native), TypeScript, Expo Router, expo-notifications, expo-background-task, `@react-native-google-signin/google-signin`, Vitest.

### Як працює перевірка

- **Нові завдання.** Завдання, яких не було на попередній перевірці. Під час першого запуску додаток лише запам’ятовує наявні завдання, щоб не завалити батьків старими.
- **Погані оцінки.** Оцінки за останні 7 днів, нижчі за поріг. «н», «зар.» та інші нечислові записи ігноруються.
- **Прив’язка оцінки до завдання.** Курс Google Класу зіставляється з предметом за назвою; номер класу на кшталт «7-А» відкидається. Якщо назви різні, відповідність задається в налаштуваннях. Обирається найближче завдання цього предмета, видане не пізніше дня оцінки й не раніше ніж за 14 днів.
- **Порожня здача.** Робота у статусі «Здано»/«Перевірено», у якої немає відповіді й вкладень, або всі вкладені файли порожні. Посилання, відео та форми вважаються змістом. Якщо файл не вдалося прочитати, тривога не здіймається.
- Кожен алерт надсилається лише один раз.

### Обмеження

- Android сам вирішує, коли запускати фонову задачу. Інтервал близько 4 годин, але система може відкладати запуск, особливо в режимі енергозбереження.
- Веб-версія лише демонстраційна: вхід у Google і «Єдину школу» з браузера не підтримується.
